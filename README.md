## 📌 **Overview**

The project proposes a **Pareto-based Genetic Ant Colony Optimization (PGA)** algorithm for **multi-UAV path planning** in **CAT-M1 terrestrial IoT sensor networks** under an **Integrated Sensing and Communications (ISAC)** framework.

The simulation models how multiple UAVs can efficiently collect IoT sensor data while minimizing:

* Total flight distance
* UAV energy consumption

The research integrates:

* PGA-based multi-objective optimization
* Real-time UAV–sensor communication
* Convex optimization–based resource allocation
* Throughput performance evaluation (up to **95%** of system capacity)

This repository is meant to help researchers and students replicate, validate, or extend the simulation results.
